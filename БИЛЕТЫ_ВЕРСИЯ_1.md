# Ответы билеты

## Задача 1

1. **`argv`** — массив строковых аргументов командной строки. В C он передаётся в `main` вместе с количеством аргументов `argc`.
2. **Простое число** — натуральное число больше 1, которое делится без остатка только на 1 и само себя.
3. **Шестнадцатеричная система** — система счисления с основанием 16. Для цифр со значениями от 10 до 15 используют буквы `A–F`.
4. **Факториал** — произведение натуральных чисел от 1 до `x`; обозначается `x!`. По определению `0! = 1`.
5. **Переполнение типа** — ситуация, когда результат не помещается в диапазон выбранного типа. Для знаковых целых чисел в C переполнение может привести к неопределённому поведению.
6. **Статус-код** — возвращаемое функцией значение, сообщающее, успешно ли выполнена операция или произошла ошибка.

## Задача 2

1. **Числовой ряд** — сумма членов последовательности, например \(a_0+a_1+a_2+\dots\).
2. **Предел последовательности** — значение, к которому приближаются члены последовательности при увеличении их номера.
3. **Абсолютная погрешность** — модуль разницы между приближённым результатом и точным значением.
4. **Критерий остановки** — условие, при выполнении которого вычисления прекращаются; например, очередное изменение результата стало меньше ε.
5. **Сходимость ряда** — свойство ряда, при котором его частичные суммы приближаются к конечному значению.
6. **Метод бисекции** — численный способ найти корень уравнения на отрезке, где функция меняет знак: отрезок делят пополам и оставляют половину со сменой знака.

## Задача 3

1. **Дискриминант** — величина \(D=b^2-4ac\), по которой определяют количество вещественных корней квадратного уравнения.
2. **Кратность числа** — отношение делимости: первое число кратно второму, если делится на него без остатка.
3. **Вырожденное уравнение** — уравнение, у которого из-за нулевого старшего коэффициента степень ниже ожидаемой. Например, квадратное уравнение становится линейным.
4. **Неравенство треугольника** — сумма длин любых двух сторон треугольника строго больше длины третьей стороны.
5. **Эпсилон-сравнение** — сравнение вещественных чисел с допуском: их считают близкими, если модуль разности меньше ε.
6. **Уникальная перестановка** — вариант перестановки, не совпадающий с другими. Если коэффициенты повторяются, некоторые перестановки дают одинаковый результат и их не нужно обрабатывать повторно.

## Задача 4

1. **Файловый поток** — последовательный канал чтения или записи файла, представленный, например, типом `FILE *`.
2. **ASCII-код** — числовой код символа в таблице ASCII. В ней есть латинские буквы, цифры, знаки и управляющие символы.
3. **Нулевой символ** — символ `'\0'`, который отмечает конец строки в C.
4. **Латинский алфавит** — буквы `A–Z` и `a–z`. Кириллица к нему не относится.
5. **Буферизация** — временное накопление данных в памяти перед чтением или записью.
6. **Конец файла** — состояние, при котором дальнейших данных для чтения нет. Его следует отличать от ошибки чтения.

## Задача 5

1. **Числовой ряд** — сумма членов бесконечной последовательности; программа приближённо вычисляет сумму конечным числом шагов.
2. **Подынтегральная функция** — функция, которую интегрируют: в записи \(\int_a^b f(x)\,dx\) это \(f(x)\).
3. **Формула Симпсона** — метод численного интегрирования, который приближает функцию параболами на небольших отрезках.
4. **Область сходимости** — значения аргумента, при которых ряд сходится к конечной сумме.
5. **Оценка погрешности** — оценка того, насколько численный результат может отличаться от точного.
6. **Особая точка** — точка, где функция не определена или ведёт себя необычно. При интегрировании важно учитывать её положение относительно интервала.

## Задача 6

1. **Рекурсия** — способ вычисления, при котором функция вызывает саму себя. Для завершения нужен базовый случай.
2. **Многоугольник** — замкнутая фигура, граница которой состоит из отрезков. В задаче по вершинам проверяется её выпуклость.
3. **Список аргументов** — аргументы переменной длины. В C для работы с ними применяют `va_list` и макросы из `<stdarg.h>`.
4. **Схема Горнера** — способ вычисления многочлена последовательным вынесением переменной за скобки, уменьшающий количество умножений.
5. **Метод дихотомии** — поиск корня уравнения на отрезке со сменой знака функции: отрезок делят пополам, пока не достигнута нужная точность.
6. **Быстрое возведение** — алгоритм вычисления степени через повторное возведение в квадрат. Он требует порядка \(\log n\) умножений для показателя \(n\).

## Задача 7

1. **Лексема** — последовательность символов между разделителями. Здесь разделителями служат пробелы, табуляции и переводы строк.
2. **Разделитель** — символ, отделяющий одну лексему от другой.
3. **Чередование лексем** — запись лексем из двух файлов по очереди: сначала из первого, затем из второго.
4. **ASCII-код** — числовое представление символа в таблице ASCII. В задаче коды переводятся в основания 4 и 8.
5. **Потоковая обработка** — чтение и обработка файла по частям, без загрузки всего его содержимого в память.
6. **Кратность позиции** — свойство номера позиции делиться на заданное число без остатка. Например, номер каждой десятой лексемы кратен 10.

## Задача 8

1. **Основание системы** — число цифр в системе счисления. Для основания `b` допустимы цифры со значениями от 0 до `b−1`.
2. **Ведущий ноль** — ноль в начале записи числа, который не меняет его значение. Например, `00042` равно `42`.
3. **Значение цифры** — числовая величина, обозначенная символом. Например, `A` соответствует 10, а `Z` — 35.
4. **Позиционная запись** — запись числа, в которой вклад цифры зависит от её позиции и основания системы.
5. **Позиционный перевод** — вычисление значения числа по его цифрам и степеням основания. Например, `1A` в системе с основанием 16 равно \(1·16+10=26\).
6. **Переполнение типа** — выход вычисления за диапазон целочисленного типа. При переводе длинного числа нужно проверять умножение на основание и прибавление очередной цифры.

## Задача 9

1. **Массив** — последовательность элементов одного типа, расположенных в памяти и доступных по индексам.
2. **Псевдослучайное число** — элемент детерминированной последовательности, которая выглядит случайной. Начальное значение генератора позволяет воспроизводить последовательность.
3. **Динамический массив** — массив, память под который выделяется во время работы программы.
4. **Линейный поиск** — последовательная проверка элементов массива до нахождения нужного или до конца массива.
5. **Ближайший элемент** — элемент с минимальной разностью по значению относительно заданного числа.
6. **Сложность алгоритма** — оценка того, как растут затраты времени или памяти при увеличении входных данных. Полный поиск ближайшего элемента для каждого `A[i]` требует порядка \(|A|·|B|\) сравнений.

## Задача 10

1. **Маркер окончания** — специальная строка, обозначающая завершение ввода. В задаче это `Stop`.
2. **Целое число** — число без дробной части. Здесь его вводят строковым представлением в выбранной системе счисления.
3. **Модуль числа** — значение числа без учёта знака: например, модуль `−7` равен 7.
4. **Система счисления** — способ записи чисел с заданным основанием и набором допустимых цифр.
5. **Произвольная точность** — возможность обрабатывать числа, длина которых ограничена доступной памятью, а не диапазоном встроенного типа. Обычно такие числа хранят строками и обрабатывают по цифрам.
6. **Сравнение модулей** — сравнение абсолютных значений чисел. Например, по модулю `−12` больше `9`, потому что \(12>9\).
