# Ответы

## Задача 1. Обработка строк

1. **Строка C** — последовательность элементов типа `char`, которая заканчивается нулевым символом `'\0'`.
2. **Длина строки** — количество символов до `'\0'`, без учёта самого завершающего нуля.
3. **Регистр символов** — различие между прописными и строчными буквами, например `A` и `a`.
4. **Нулевой символ** — `'\0'`, специальный символ со значением 0, обозначающий конец строки в C.
5. **Динамическая память** — память, которую программа запрашивает во время работы, например через `malloc`; после использования её освобождают через `free`.
6. **Стабильное разбиение** — распределение символов по группам с сохранением их исходного порядка внутри каждой группы. Это требуется для цифр, букв и прочих символов в `-n`.
7. **Скользящее копирование** — перемещение содержимого массива или строки так, чтобы порядок выбранных элементов сохранился. При реализации важно не затереть ещё не обработанные символы.
8. **Алгоритм Фишера—Йетса** — алгоритм случайного перемешивания массива, который на каждом шаге выбирает случайный элемент из ещё не перемешанной части. Он помогает получать перестановку без повторения или пропуска элементов.
9. **Байтовая длина** — размер строки в байтах. Для ASCII она совпадает с числом символов, но в UTF-8 один символ может занимать несколько байтов.

## Задача 2. Сортировка сотрудников

1. **Структура** — пользовательский тип данных, объединяющий поля разных типов, например ID, имя, фамилию и зарплату.
2. **Компаратор** — функция, сравнивающая два элемента: возвращает отрицательное значение, ноль или положительное значение.
3. **Порядок сортировки** — правило, по которому упорядочивают элементы: в этой задаче сначала зарплата, затем фамилия, имя и ID.
4. **Лексикографическое сравнение** — сравнение строк слева направо до первого различающегося символа, как в словаре.
5. **`qsort`** — стандартная функция C для сортировки массива. Ей передают адрес массива, число элементов, размер элемента и функцию-компаратор.
6. **Динамический массив** — массив, память под который выделяется во время выполнения программы. Его размер может зависеть от числа прочитанных записей.
7. **Строгий слабый порядок** — согласованное правило сравнения элементов, необходимое сортировке. Например, если `a` меньше `b`, то `b` не должен одновременно считаться меньше `a`.
8. **Составной ключ** — последовательность критериев сравнения. Здесь сотрудник сравнивается сначала по зарплате, а при равенстве — по следующим полям.
9. **Переполнение компаратора** — возможная ошибка при сравнении целых вычитанием: разность может выйти за диапазон типа. Надёжнее сравнивать значения через условия.

## Задача 3. Поиск подстроки в файлах

1. **Подстрока** — непрерывная последовательность символов, которую ищут внутри текста.
2. **Файловый поток** — объект `FILE*`, через который программа последовательно читает файл или записывает в него данные.
3. **Номер строки** — позиция строки в файле; по условию нумерация начинается с 1.
4. **Скользящее окно** — участок текста длины искомой строки, который последовательно сравнивают с образцом.
5. **Перекрывающиеся вхождения** — совпадения, использующие общие символы. Например, в `aaaa` подстрока `aa` начинается с трёх разных позиций.
6. **Вариадическая функция** — функция с переменным числом аргументов. Для работы с ними в C применяют `va_list` и макросы из `<stdarg.h>`.
7. **Межстрочное совпадение** — вхождение подстроки, которое начинается в одной строке и продолжается после перевода строки.
8. **Наивный поиск** — алгоритм, который проверяет образец в каждой возможной позиции текста. Его простая реализация может повторно сравнивать одни и те же символы.
9. **Потоковый алгоритм** — алгоритм, обрабатывающий текст по мере чтения, не загружая весь файл целиком. Он должен хранить достаточно предыдущих символов, чтобы обнаружить совпадения на границах блоков.

## Задача 4. Выбор файлов для резервной копии

1. **Вместимость** — максимальный суммарный размер файлов, который может поместиться на накопителе.
2. **Важность файла** — числовая ценность файла, используемая при выборе резервных копий.
3. **Подмножество** — выбранная часть исходного набора файлов.
4. **Задача о рюкзаке** — задача выбора предметов с размером и ценностью при ограниченной вместимости. Здесь размер файла — вес, важность — ценность.
5. **Динамическое программирование** — метод решения задачи через более простые подзадачи с сохранением их результатов.
6. **Оптимальный набор** — допустимый набор файлов с максимально возможной суммарной важностью.
7. **Восстановление решения** — получение списка выбранных файлов после вычисления максимальной важности. Одного значения максимума недостаточно, если требуется вывести сами файлы.
8. **Псевдополиномиальная сложность** — сложность алгоритма, зависящая от числового значения вместимости, например `O(n × capacity)`, а не только от длины записи вместимости.
9. **Инвариант динамики** — утверждение о смысле каждой ячейки таблицы динамического программирования. Например: ячейка хранит максимальную важность для первых `i` файлов при данной вместимости.

## Задача 5. Форматированный вывод

1. **Форматная строка** — шаблон, задающий, какие данные и в каком виде нужно вывести.
2. **Спецификатор** — часть формата, указывающая, как преобразовать значение, например `%d` или пользовательский `%Ro`.
3. **Поток вывода** — назначение для записываемых данных, например файл или стандартный поток `stdout`.
4. **Вариадическая функция** — функция с переменным числом аргументов; для доступа к ним используют `va_list`.
5. **Система счисления** — способ записи числа с помощью основания и набора цифр.
6. **Дамп памяти** — отображение байтов значения в выбранном формате. В этой задаче байты выводятся двоичными строками.
7. **Продвижение аргументов** — автоматическое преобразование некоторых типов при передаче через `...`. Например, `float` передаётся как `double`.
8. **Разбор формата** — последовательное чтение форматной строки с распознаванием обычных символов и спецификаторов.
9. **Представление Зекендорфа** — запись числа как суммы различных чисел Фибоначчи без соседних использованных чисел; в условии коэффициенты записываются от младшего к старшему с дополнительной единицей-терминатором.

## Задача 6. Форматированный ввод

1. **Форматный ввод** — чтение текста с преобразованием по формату, как в `scanf`, `fscanf` или `sscanf`.
2. **Адрес переменной** — место переменной в памяти. Функции ввода передают его, чтобы записать туда результат.
3. **Преобразование** — разбор входных символов и преобразование их в значение указанного типа.
4. **Спецификатор ввода** — элемент формата, задающий, как разобрать текст и куда записать полученный результат.
5. **Частичный разбор** — ситуация, когда удалось прочитать только некоторые значения до ошибки или несовпадения формата.
6. **Основание системы** — число, задающее систему счисления. Для дополнительных спецификаторов допустимый диапазон — от 2 до 36; согласно условию вне диапазона используется основание 10.
7. **Продвижение указателей** — после каждого успешного преобразования функция должна перейти к следующему указателю из списка аргументов. Неверный порядок или тип указателя ведёт к ошибкам записи.
8. **Счёт преобразований** — количество значений, успешно считанных и сохранённых. Функции семейства `scanf` используют это число как результат.
9. **Машина состояний** — модель разбора, в которой программа меняет состояние в зависимости от текущего символа. Она помогает организовать обработку спецификаторов, знаков, цифр и ошибок.

## Задача 7. Нормы векторов

1. **Вектор** — упорядоченный набор координат в пространстве.
2. **Координата** — отдельное числовое значение, составляющее вектор.
3. **Норма** — функция, определяющая длину вектора и удовлетворяющая математическим свойствам длины.
4. **Бесконечная норма** — максимум модулей координат вектора: \(\|x\|_\infty=\max_j |x_j|\).
5. **p-норма** — величина \(\left(\sum_j |x_j|^p\right)^{1/p}\), где \(p\ge1\).
6. **Указатель на функцию** — переменная, содержащая адрес функции и позволяющая вызвать её через указатель.
7. **Положительная определённость** — свойство матрицы \(A\), при котором \(x^T A x>0\) для любого ненулевого вектора \(x\). Для стандартной положительной определённости матрица также симметрична.
8. **Квадратичная форма** — выражение \(x^T A x\), построенное из вектора и матрицы. В индуцированной норме \(\|x\|_A=\sqrt{x^T A x}\).
9. **Универсальный указатель** — `void *`, который может хранить адрес объекта без указания его типа. Перед использованием адрес нужно трактовать с корректным типом; для указателей на функции в C следует учитывать отдельные правила, поскольку `void *` не является универсальным типом указателя на функцию.

## Задача 8. Сложение больших чисел

1. **Разряд** — позиция цифры в записи числа; её вес зависит от основания системы.
2. **Перенос** — значение, добавляемое к следующему разряду, когда сумма цифр достигает основания системы.
3. **Основание системы** — количество различных цифр, используемых в системе счисления.
4. **Арифметика строк** — вычисления над числами, чьи цифры хранятся в строках, а не во встроенном числовом типе.
5. **Сложение в столбик** — сложение справа налево по разрядам с передачей переноса.
6. **Ведущий ноль** — ноль перед значащими цифрами числа, который не меняет значение записи.
7. **Произвольная точность** — возможность работать с числами, длина которых ограничена памятью, а не диапазоном `int` или `long long`.
8. **Нормализация числа** — приведение записи к стандартному виду, например удаление ведущих нулей, кроме случая самого числа 0.
9. **Корректность переноса** — свойство алгоритма правильно передавать перенос в следующую позицию и сохранять итоговое значение суммы в каждом разряде.

## Задача 9. Конечная запись дроби

1. **Основание системы** — число, задающее систему счисления и диапазон допустимых цифр.
2. **Дробная часть** — часть числа после разделителя, представляющая долю от единицы.
3. **Период** — повторяющаяся группа цифр в бесконечной записи дроби.
4. **Конечная запись** — представление дроби, которое заканчивается после конечного числа цифр.
5. **Сокращённая дробь** — дробь, числитель и знаменатель которой не имеют общего делителя больше 1.
6. **Знаменатель** — нижняя часть дроби \(p/q\), определяющая размер дробных долей.
7. **Критерий конечности** — после сокращения дроби \(p/q\) запись в основании `b` конечна тогда и только тогда, когда все простые делители `q` делят `b`.
8. **Разложение знаменателя** — представление знаменателя как произведения простых множителей. Оно позволяет проверить критерий конечной записи.
9. **Ошибка представления** — отличие хранимого значения `float` или `double` от исходной десятичной дроби. Из-за неё проверка точной конечности через приближённые вещественные значения может дать неверный ответ.

## Задача 10. Переразложение многочлена

1. **Многочлен** — конечная сумма слагаемых, содержащих коэффициенты и степени переменной.
2. **Степень** — наибольший показатель переменной с ненулевым коэффициентом.
3. **Коэффициент** — числовой множитель при степени переменной.
4. **Сдвиг переменной** — замена записи через \(x\) на степени выражения \((x-a)\).
5. **Точка разложения** — значение \(a\), вокруг которого многочлен записывают в степенях \((x-a)\).
6. **Динамический результат** — массив коэффициентов, память под который выделяется во время работы функции и передаётся вызывающему коду через указатель.
7. **Формула Тейлора** — формула представления многочлена через степени отклонения от точки \(a\): \(g_k=f^{(k)}(a)/k!\).
8. **Производная порядка k** — результат последовательного дифференцирования функции \(k\) раз. В разложении Тейлора её значение в точке \(a\) задаёт коэффициент при \((x-a)^k\) после деления на \(k!\).
9. **Оценка округления** — учёт отклонения вычисленного коэффициента от точного из-за ограниченной точности вещественных чисел; эпсилон задаёт допустимую погрешность.
